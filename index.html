Installation Steps

  1. Download the mod JAR file using the button above
  2. Open Minecraft launcher and select "Fabric" profile
  3. Click on folder icon to open game directory
  4. Navigate to mods folder (create it if missing)
  5. Paste the downloaded JAR file
  6. Launch Minecraft and enjoy!

Requirements

  • Minecraft Java Edition 1.20.4+
  • Fabric Loader installed
  • Fabric API mod (included in bundle)
  • 4GB+ RAM allocated to Minecraft
